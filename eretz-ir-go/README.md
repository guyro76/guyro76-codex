# ארץ-עיר GO! 🌍🏙️

משחק ארץ-עיר משפחתי, חכם ומודרני — **PWA מלאה שעובדת גם בלי אינטרנט**, בלי חשבונות, בלי פרסומות ובלי עלויות AI.

## מה יש בפנים

- **9 קטגוריות קלאסיות** (ארץ, עיר, חי, צומח, דומם, שם של בן, שם של בת, מקצוע, אישיות) + ספרייה של 50+ קטגוריות, ובחירה של 5–12 למשחק.
- **קטגוריות אישיות** עם רשימת מילים התחלתית.
- **9 מצבי משחק:** יחיד נגד השעון, דו-קרב על אותו מכשיר (עם מעבר תורות והסתרת תשובות), שיתוף פעולה על לוח אחד, טורניר רב-סיבובי, תרגול חופשי, אתגר יומי שעובד Offline (אלגוריתם מבוסס תאריך), **⚡ ראש בראש** (קטגוריה אחת, 45 שניות, כמה שיותר תשובות) **🔗 שרשרת** (כל תשובה מתחילה באות האחרונה של הקודמת) ו-**🎴 קלף מסתורי** (הקטגוריות נבחרות על ידי המשחק ונחשפות רק אחרי הגרלת האות).
- **🎴 קלפי כוח** (אופציונליים): ⏳ +15 שניות, 🔁 החלפת אות, 💡 רמז מתנה, ✖️2 ניקוד כפול על קטגוריה נבחרת.
- **🔊 צלילי משחק** מסונתזים ב-WebAudio — בלי קובצי אודיו, עובדים Offline, ונשלטים ממתג בהגדרות.
- **פרופילים מקומיים** עם שם, אווטאר, צבע, **מגדר וגיל** — המשחק פונה לכל שחקן/ית בלשון הנכונה ומתבדח בהתאם לגיל.
- **"ארצי" 🤖** — בוט הרמזים המקומי: מאומן על כל המאגר, 3 דרגות רמז + חשיפה, פועל 100% במכשיר ללא שום API בתשלום.
- **מנוע בדיקת תשובות היברידי:** נרמול עברית (ניקוד, סופיות, כתיב מלא/חסר, ה"א הידיעה, גרשיים), בדיקת אות, בדיקת קטגוריה ("בננה היא לא עיר"), Fuzzy Matching לתיקוני כתיב, וחסימת ג'יבריש.
- **אימות אונליין:** תשובה שאינה במאגר נבדקת מול ויקיפדיה העברית לפני שהיא נכנסת למאגר; בלי אינטרנט — ערעור לאישור הורה.
- **צביעה מיידית:** תשובה נכונה ירוקה ✅, שגויה אדומה ❌, בבדיקה צהובה ⏳.
- **ניקוד קלאסי מורחב:** 10 ייחודית / 5 זהה / 0 שגויה + מדד מקוריות 0–100, בונוס מהירות, בונוס "בלי רמז", בונוס גילוי ובונוס השלמה.
- **אוסף המילים שלי** — אלבום קלפים עם עובדות, סינון ומועדפים; השלמה אוטומטית מהמילון האישי במשחקים הבאים.
- **לוח שיאים משפחתי** (היום/שבוע/חודש/תמיד), הישגים ומדליות, רצף יומי.
- **מצב הורה** מוגן PIN: אישור ערעורים וניהול המאגר.
- **פרטיות מלאה:** הכול ב-IndexedDB במכשיר. ייצוא/ייבוא פרופיל, מחיקת מידע מלאה.

## התקנה והרצה

```bash
cd eretz-ir-go
npm install
npm run icons     # יצירת אייקוני ה-PWA (פעם אחת)
npm run dev       # פיתוח: http://localhost:5173
npm test          # 57 בדיקות יחידה (vitest)
npm run test:e2e  # 5 בדיקות E2E בדפדפן אמיתי (playwright) — דורש build קודם
npm run build     # בנייה לפריסה — תיקיית dist/
npm run preview   # תצוגה מקדימה של הבנייה
npm run seed:report  # דו"ח כיסוי המאגר לפי אות וקטגוריה
```

## פריסה

**המשחק חי:** https://guyro76.github.io/guyro76-codex/

ה-workflow `.github/workflows/eretz-ir-go-pages.yml` מריץ בכל דחיפה בדיקת טיפוסים, 57 בדיקות יחידה, 5 בדיקות E2E בדפדפן, בנייה, ואז דוחף את התוצר לענף `gh-pages` — כך שהאתר החי מתעדכן אוטומטית. אין צורך בשום סוד חיצוני.

תיקיית `dist/` היא אתר סטטי, כך שאפשר גם לפרוס ל-Vercel / Netlify. הבנייה מכבדת `BASE_PATH` ולכן עובדת גם בשורש דומיין וגם בתת-נתיב. ה-Service Worker וה-Manifest נוצרים אוטומטית, והאפליקציה ניתנת להתקנה במסך הבית (Android, iOS, Desktop). להעלאה לחנויות — ראו `STORE_DEPLOYMENT.md`.

## משחק בשני מכשירים (אופציונלי)

המשחק המקומי לא דורש שרת. למשחק מרחוק יש שכבת `MultiplayerProvider` (ראו `src/multiplayer/`) וסכמת Supabase מוכנה ב-`supabase/schema.sql`. מגדירים `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` בקובץ `.env` (ראו `env.example`) — אין מפתחות בקוד.

## ארכיטקטורה בקצרה

```
src/
  lib/        מנועים: hebrew (נרמול), validation, scoring, artzi (רמזים),
              persona (מגדר/גיל), letters (הגרלה), daily, verifyOnline, roundEngine
  data/       categories, seed (מאגר מאומת), tips, achievements
  db/         Dexie/IndexedDB: פרופילים, מילון אישי, משחקים, ידע שנוסף
  store/      Zustand: appStore (ניווט), gameStore (מכונת מצבי המשחק)
  screens/    כל 20+ המסכים
  components/ CategoryCard (כולל השלמה אוטומטית ורמזים), Modal, TopBar
  multiplayer/ ממשק Provider למשחק מרחוק
```

ראו `LIMITATIONS.md` למגבלות ידועות.
