# מגבלות ידועות — ארץ-עיר GO! v1.0

1. **משחק בשני מכשירים** — ממשק ה-Provider והסכמה קיימים, אך מסך יצירת חדר/QR יופעל רק לאחר חיבור Supabase (בכוונה אין כפתור מת; יש מסך הסבר להורים).
2. **תמונות** — במאגר ה-Seed אין תמונות מוטמעות (כדי לא להפר רישיונות). תמונות אמיתיות נטענות ונשמרות במטמון כאשר תשובה מאומתת מול ויקיפדיה, כולל קרדיט ומקור. ערכי Seed מסומנים "ממתין לתמונה".
3. **אימות אונליין** — מבוסס חיפוש כותרות בוויקיפדיה העברית. ערך שאינו קיים בוויקיפדיה (למשל סלנג) יעבור רק דרך אישור הורה. תשובה שאושרה בערעור מזכה בניקוד מהמשחק הבא, לא רטרואקטיבית.
4. **מודל AI מתקדם (WebLLM)** — לא נכלל בגרסה זו. "ארצי" פועל על מאגר הידע המקומי (שכבות 1–2 של האפיון); זה מספיק לרמזים, לתיקוני כתיב ולסיווג, בלי הורדת מודל של ג'יגות.
5. **מצב קולי** — לא מומש (דורש Web Speech API שאינו זמין בכל הדפדפנים ללא רשת).
6. **מאגר** — כ-1,000 ערכים מאומתים ידנית עם כיסוי לכל אות בקטגוריות הקלאסיות; המאגר גדל תוך כדי משחק דרך אימות ויקיפדיה. סקריפט Wikidata להרחבה נמצא ב-repo הנפרד content-builder.
7. **מצב "שרשרת"** — עדיין לא מומש. קלפי כוח (זמן נוסף, החלפת אות, רמז מתנה, ניקוד כפול) ומצב "ראש בראש" (בליץ) — מומשו במלואם.

הערה: צריכת Content Packs (טעינה, אימות checksum, מיזוג ועדכון אוטומטי יומי) ממומשת במלואה — ראו את הסעיף "עדכוני תוכן" במסך ההגדרות ואת `src/lib/contentPack.ts`.
