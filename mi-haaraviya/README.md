# מי הערביה

סרטון סאטירה קצר (60 שניות) בעברית: אחינועם ניני ומירה עוואד רבות מי מהן הערבייה,
כל אחת מאשימה את השנייה, והתיק נסגר בהסדר פשרה בעיתון — שתיהן ערביות.

הסרטון בנוי כחבילת גרפיקת שידור מעל תצלום במה, ועובר בסוף לעמוד עיתון.
הפסקול מקורי ומסונתז מאפס — אין בו שום הקלטה, דגימה או שיר קיים.
**זו סאטירה** — אף אחד מהמשפטים לא נאמר במציאות, ו״המזרח התיכון״ ו״ערוץ הפשרה״ הם בדיוניים.
הסימון מופיע בכל פריים ובחותמת בסוף.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `video.template.html` | המקור. כל התסריט, העיצוב וציר הזמן |
| `build.mjs` | מטמיע את התצלום ואת הגופנים כ־data URI ומייצר קובץ אחד עצמאי |
| `mi-haaraviya.html` | הפלט — נגן עצמאי, בלי תלות ברשת |
| `audio.mjs` | הפסקול — סינתיזה מאפס ל־`audio.wav` |
| `shoot.mjs` | צילום פריימים לבדיקה ויזואלית |
| `encode.mjs` | קידוד ל־MP4 |
| `assets/stage.jpg` | תצלום הבמה |
| `fonts/` | Karantina, Frank Ruhl Libre, Assistant (Google Fonts, OFL) |

## בנייה

```bash
node audio.mjs                      # -> audio.wav
ffmpeg -i audio.wav -c:a libmp3lame -b:a 128k audio.mp3
node build.mjs                      # -> mi-haaraviya.html (תמונה, גופנים ופסקול מוטמעים)
TIMES="3,9,26,51.4,58.6" node shoot.mjs   # -> frames/
node encode.mjs                     # -> mi-haaraviya.mp4 (וידאו שקט)
ffmpeg -i mi-haaraviya.mp4 -i audio.wav -map 0:v -map 1:a \
       -c:v copy -c:a aac -b:a 192k -shortest out.mp4
```

`shoot.mjs` ו־`encode.mjs` דורשים playwright ו־ffmpeg מקומיים.

## איך זה עובד

הכל נגזר מפונקציה אחת, `render(t)`, שהיא פונקציה טהורה של הזמן — בלי מצב מצטבר
ובלי אנימציות CSS. לכן אפשר לגרור את הסרגל לכל נקודה ולקבל בדיוק את אותו פריים,
ולכן הקידוד מדויק: `encode.mjs` פשוט קורא ל־`__seek(t)` 1500 פעם ומצלם.

ציר הזמן: פתיח (0—7.4) · ההאשמה (7.4) · הראיות (13.2) · הנגד (24.4) ·
בית המשפט (39.4) · פסק הדין (50.4).

## הפסקול

`audio.mjs` מסנתז הכל מאפס — Karplus-Strong לעוד, רעש מסונן לדרבוקה
ולוווששים, סינוסים לפעמונים, ו־Schroeder reverb על המאסטר. אין דגימות.

המוזיקה במאקאם חיג'אז על רה, וזאת הבדיחה: זה הסולם שבאמת משותף לשתי
המסורות. הסקציות נעולות לביטים של הווידאו — הקצב נכנס עם ההאשמה
הראשונה, נעצר בהתנגשות ב־37.6, מתדלדל לתקתוק שעון בבית המשפט,
וחוזר מלא בפסק הדין. שם שני קולות פורטים את המוטיב יחד במרווח
של שלישית — סוף סוף בהרמוניה.

בנגן הקול מתחיל מושתק, כי דפדפנים מרשים ניגון אוטומטי רק בלי סאונד.
כפתור **קול** בסרגל מפעיל אותו, והסרגל לא נעלם כל עוד הוא כבוי.
כשהקול פועל, אלמנט האודיו הוא שעון האב: `t = snd.currentTime`, כך
שאין דריפט בין התמונה לפסקול.

### להחליף בשיר משלכם

אם יש לכם רישיון להקלטה, שימו אותה במקום `audio.mp3` ובנו מחדש:

```bash
AUDIO=my-track.mp3 node build.mjs
```

השיר המקורי מהאירוויזיון לא נמצא כאן ולא יכול להיות — הוא מוגן
בזכויות יוצרים.
